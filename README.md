# The Corporate Lens

A clean three-page Next.js website for The Corporate Lens, a corporate media and storytelling platform built around the tagline "Beyond the Headlines."

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- next/font with Cinzel and Inter

## Routes

- `/`
- `/about`
- `/contact`

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
